# Roadmap: Beyond Isolated Atoms

**Spec:** `docs/superpowers/specs/2026-09-25-beyond-isolated-atoms.md`
**Goal:** the tool students and researchers reach for to *see* electronic
structure — from one electron around a proton, through every atom, to the
first bonds and the molecules chemistry is taught with — without ever
showing a picture prettier than it is true.

Each phase ships on its own: tests green, verified live at desktop and phone
sizes, deployed. Run them in order; each plan names what it takes from the
phases before it.

## Shared contracts (fixed in the spec, used by name across plans)

- `src/field_source.ts` — `FieldSource`, `FieldRecipe` (`hydrogenic`,
  `combination`, `polarized1s`, `h2plus`, `gaussianMO`, `gaussianDensity`),
  `generateFieldMesh(source, resolution, enclosedFraction)` (spec §4.1).
- `public/molecules/` data format and `src/molecules/loader.ts`
  (`loadMoleculeIndex`, `loadMoleculeMeta`, `loadDensityGrid`, `loadBasis`)
  (spec §4.2).
- `src/url_state.ts` — `encodeState`, `applyState`, `registerUrlKeys`; key
  grammar in the Phase 2 plan, Task 5 (spec §4.3).
- `src/validation/references.ts` — `ValidationRow`, `VALIDATION`, appended by
  every phase with computed (never hand-typed) values (spec §4.4).

## What the plans found while being written

These came from prototyping the physics, and the spec was corrected to match:

- **Hybrids:** the textbook `(2s + 2p)/√2` points its big lobe the wrong way
  with hydrogen's 2s sign; the plan uses `−2s` so each lobe points along its
  label (Phase 1).
- **Stark effect:** an n = 2 electron is no longer bound above
  F = 1/256 a.u.; its slider stops there (Phase 1).
- **Ions:** plain LDA misses ionisation energies by 12–22 % for O, F, S, so
  energies use spin-polarised LDA (all of H–Ar within 10 %); most anions,
  Cl⁻ included, are unbound in LDA and say so (Phase 3).
- **Relativity:** light atoms are *not* unchanged by relativity (argon's total
  energy moves 0.30 %); the check is agreement with NIST's relativistic
  values instead (Phase 4).
- **H₂⁺:** the exact solver was prototyped: R_e = 1.99719 a₀,
  E(R_e) = −0.6026346 Ha (Phase 5).
- **Current app bugs found in passing:** panel text contrast below WCAG AA —
  breadcrumb 1.59:1, MUI blue on the light cards 2.89:1, overlay notes 2.50:1
  (fixed in Phase 7).

## Decisions only the owner can make

Each is asked at the task that needs it; collected here so none is a
surprise.

1. **Licence** (Phase 7, Task 1): recommended MIT for the code and
   CC-BY-4.0 for the generated molecule data.
2. **Analytics** (Phase 7, Task 1): recommended CloudFront access logs only
   (page loads and molecule views; no cookies, no lesson tracking).
3. **Domain** (Phase 7, Tasks 1 and 21): pick one before the first Zenodo
   release so the citation carries the lasting URL.
4. **Zenodo DOI** (Phase 7, Task 12): make the GitHub repo public, enable it
   in Zenodo, publish a release, send back the DOI.
5. **Repository size** (Phases 5–6): generated molecule data is committed —
   roughly 15–20 MB for the bond scans and 50 MB for the library.
6. **He₂ at full CI** (Phase 5): four electrons, beyond the spec's "full CI
   for two electrons"; the plan does it because it is still cheap.
7. **A molecule whose dipole misses** its reference by more than 10 %
   (Phase 6, Task 7): the plan stops and asks rather than loosening the
   tolerance, offering a larger basis for that molecule.
8. **Test time** (Phase 3): about 60 s more CPU in the default suite; the
   plan names which cases move behind `ATOM_SLOW_TESTS=1` if wall time grows
   by more than 20 s.
